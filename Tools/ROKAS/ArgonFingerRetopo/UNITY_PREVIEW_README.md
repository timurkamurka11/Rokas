# ROKAS — проверить настоящую перестроенную кисть в Unity

**Только изолированный PR #13:** `codex/bedsleep-argon-import-candidate`. Рабочую сцену V10, главную ветку и сохранения игры этот способ **не меняет**.

## Один запуск в локальной рабочей копии

1. Закройте Play Mode Unity (редактор можно оставить открытым).
2. Откройте **существующий** проект `D:\Rokas\Rokas-FULL-R11-FINISHED-UI COPY`, в котором находится Git-репозиторий. Не создавайте второй клон.
3. Запустите из папки проекта `Tools\ROKAS\ArgonFingerRetopo\ROKAS_ARGON_UNITY_PREVIEW.bat`. Нужны Git for Windows, GitHub CLI (`gh`) и авторизация один раз через `gh auth login`.
4. BAT выполнит `git fetch`; если открыт не тестовый branch, перед переключением спросит разрешение и откажется переключаться при незакоммиченных локальных изменениях. На тестовой ветке сделает **только** `git pull --ff-only` (без merge в `main` или V10).
5. BAT скачает **проверенный Blender+Unity 25-bone FBX** из последнего успешного GitHub Actions run `argon-finger-local-root-bridge-qa.yml` и поместит в `Assets/Rokas/BedSleep/ArgonIntegration/LocalRootBridgeQA/`. Модель и тестовая сцена находятся в `.gitignore`: собственный BAT для push не отправит их как бинарные активы.
6. Дождитесь импорта ассетов Unity. В меню Unity откройте **ROKAS > Bed Sleep > Argon > Open latest connected hand in Unity**.
7. Редактор откроет отдельную сцену **ROKAS_Argon_Hand_Inspection**: настоящая скиннированная геометрия для вращения в Scene View. Можно рассмотреть основание указательного, мизинца, межпальцевые перепонки, ладонь и запястье. Изменения в этой сцене не применяются к игровому V10.

## Текущие ограничения

- Это **просмотр топологии кисти**, а не готовая новая игровая анимация с часами. Часы, OLED, рукав, bed-ceiling и игровой контроллер остаются в отдельном уже существующем preview prefab и V10.
- Отчёт GitHub Actions доказывает, что FBX импортируется, имеет реальные 25 костей и деформируется в Unity. **Не доказывает**, что форма кисти уже выглядит естественной.
- Чтобы вернуться к рабочей ветке, сначала сохраните или закоммитьте собственные изменения. Затем используйте свой привычный BAT/команды Git. Не выполняйте `git merge` тестовой ветки в main ради одного просмотра.
- Если `gh` отсутствует: установите `winget install --id GitHub.cli -e`, откройте новый терминал и выполните `gh auth login`.
- Если GitHub Actions ещё работает, подождите до окончания успешной проверки `ROKAS Argon - Local Root Bridge Geometry Candidate`; BAT не скачивает непроверенные FBX.
- Всё здесь находится **в той же локальной копии**; архива игры, EXE и отдельной Review-копии не создаётся.
