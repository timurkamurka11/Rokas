# ROKAS Visual Novel Intro Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first production-looking, click-advanced ROKAS visual-novel intro after Enter World, then safely hand off to the existing Home and remember completion with a temporary versioned local flag.

**Architecture:** Keep the existing Main Menu, `EnterWorldCurtain`, `RokasAudio`, `RokasAssets`, Home, and Yarn Spinner architecture. Add a dedicated VN Yarn project plus `VnIntroController`, `VnIntroDialoguePresenter`, `VnIntroView`, and replaceable `IVnIntroProgress`; normal completion and Skip converge on one guarded `CompleteIntroAndGoHome()` path in `RokasBootstrap`.

**Tech Stack:** Unity 6000.3.19f1, C#, uGUI, Yarn Spinner Unity v3.1.2, NUnit/Unity Test Framework 1.4.6, GameCI `unity-test-runner@v4`, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-09-12-vn-intro-design.md`

## Global Constraints

- Continue the existing ROKAS Unity project; do not start a new project.
- Do not work on combat.
- Yarn Spinner is the only narrative engine for this iteration.
- Preserve the existing Main Menu / Enter World / audio / transition architecture unless a test proves a change is required.
- Use the exact temporary completion key `rokas.vn_intro.completed.v1`.
- Mark completion only after the existing Home has been constructed successfully and `RokasBootstrap.View != null`.
- Pause blocks only VN progression/input and must never write `Time.timeScale`.
- Mute is transient; it must not mutate saved `SettingsData.masterVolume`, `musicVolume`, or `sfxVolume`.
- Natural completion and Skip must call the same `CompleteIntroAndGoHome()` path.
- Import exactly the 10 unique PNGs from `Import_Recommended/`; never import `Source_All_Submissions/` duplicates.
- `VN_BusStop_PhoneMessage_Mina.png` is a complete full-frame scene; do not rebuild it from overlays.
- Character sheets are source/crop textures only; do not render the whole sheet as a dialogue portrait.
- Do not extend permanent `SaveData` for the intro flag.
- Do not touch `development`, force-push, use `reset --hard`, or use `git clean` as a shortcut.
- Do not advance `integration/rokas-unified` automatically.
- TDD for code changes; unexpected failures use systematic debugging; completion requires fresh verification evidence.

```csharp
public override async YarnTask RunLineAsync(LocalizedLine line, LineCancellationToken token)
{
    if (pendingAdvance != null) throw new InvalidOperationException("VN already has a pending line gate.");
    CurrentSpeaker = line.CharacterName ?? string.Empty;
    CurrentLine = line.TextWithoutCharacterName.Text.Trim();
    pendingAdvance = new YarnTaskCompletionSource();
    LineChanged?.Invoke();
    await pendingAdvance.Task;
    pendingAdvance = null;
}

public bool Advance()
{
    if (pendingAdvance == null) return false;
    YarnTaskCompletionSource gate = pendingAdvance;
    pendingAdvance = null;
    gate.TrySetResult();
    return true;
}
```
