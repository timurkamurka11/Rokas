# Ближайший незавершённый этап

1. Открыть существующий проект в Unity **6000.3.19f1**, дождаться импорта пакетов и компиляции. Исправить реальные ошибки Console, если они появятся.
2. Выполнить **Rokas → Validate Project**, EditMode и PlayMode-тест `IllustratedHomeCanAcceptFightReturnAndClaimExactlyOnce`. Проверить паузу и недоступность фоновых кнопок при открытой панели.
3. В `Assets/Rokas/Scenes/Rokas.unity` пройти первый контракт вручную: YOMI → чай → портал → бой → домой → получить оплату → перезапуск. Осмотреть Game view в 1920×1080 и 1280×720, анимацию, читаемость, расположение целей и громкость. Исправить только выявленные дефекты.
4. Собрать и запустить Windows x64 player; сохранить фактические результаты в handoff, commit и push в `development`.

Не повторять Core или генерацию уже сохранённых ассетов. Новые комнаты, системы развития и контракты в этот этап не входят.
