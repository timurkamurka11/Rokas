# Незакрытые проверки первого запуска

- **Unity compilation / PlayMode: NOT AVAILABLE.** В среде разработки нет Unity Editor или Unity MCP. Core CI компилирует только доменную C#-логику, поэтому не подтверждает компиляцию Presentation, Editor или Unity-тестов.
- **Импорт сцены и пакетов не выполнен Unity.** Файлы, GUID, asmdef и типы bindings проверены статически. Первая реальная проверка: открыть проект в Unity 6000.3.19f1, дождаться импорта и выполнить `Rokas → Validate Project`. Созданный самим Unity `Packages/packages-lock.json` следует сохранить после успешного разрешения пакетов.
- **Game view, анимация и звук не проверены в запущенной игре.** Существующие реализации и все 17 бинарных ассетов сохранены. После PlayMode-теста требуется ручной проход в 1920×1080 и проверка читаемости/масштаба в 1280×720. Конкретные визуальные дефекты без осмотра не утверждаются.
- **Windows build: NOT ATTEMPTED.** Выполнять после подтверждения первого цикла в PlayMode.

Незавершённых загрузок ассетов нет. Следующая точная точка записана в `SESSION_HANDOFF.md`; повторение генерации и Core review не требуется.
